# Classic Grey formal shirt

Open `/mockup-lab?product=grey-shirt`. This ghost mannequin reference was generated
from the user's ImageKit Classic Grey shirt photo. The template preserves its
woven fabric, pocket, collar and button placket, with an inset alpha mask and
0.8 px feathering. Partial edge coverage is retained for a softer silhouette.

The default `#999ba1` colour reproduces the reference pixels within the mask.
Other colours use the shared reference-pixel renderer; button protection is
relative to the fabric brightness to avoid grey discs on dark colour variants.
Left and right chest logo zones are available. Sizing assumes a 52 cm chest;
measure the garment before using the preview for production sizing.

Validate: `npm run check-template -- solid-formal-shirt`.
