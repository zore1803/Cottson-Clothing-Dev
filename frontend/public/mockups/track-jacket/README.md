# Track jacket

Open `/mockup-lab?product=track-jacket-black`.

The ghost mockup retains the short collar, full sleeves, split pockets,
ribbed cuffs and hem from the supplied jacket reference. The person,
white undershirt and chest lettering are removed.

The inset silhouette uses 0.8 px feathering. Fabric recolouring preserves
folds, with softer shadows for white. A metallic zipper overlay preserves
the teeth and slider while the surrounding fabric changes colour.
Left and right chest logo areas avoid the zipper.

Only a front view is available. Logo sizing assumes a 52 cm chest;
accurate production sizing requires garment measurements.

Validate with `npm run check-template -- track-jacket`.
