# Black zip hoodie ghost mockup

Open `/mockup-lab?product=zip-hoodie-black`.

Generated from the supplied ImageKit jacket reference. The mockup retains the
hood, split kangaroo pockets, ribbed cuffs and hem without the person, undershirt
or chest lettering. The inset alpha mask is feathered by 0.8 px.

Reference-pixel recolouring preserves fabric shading; `details-zipper.png`
supplies the original zipper pixels. `details-zipper-refined.png` isolates the
metallic teeth and pull with a soft luminance mask; the surrounding fabric and
dark zipper tape recolour with the jacket instead of leaving a black stripe.
The hardware mask covers both neckline branches, the full slider and the full
length of the teeth, with a smooth transition around the metallic edges.
Left and right chest logo zones avoid the zipper. Only a front view is available.
Logo sizing assumes a 52 cm chest and needs actual garment measurements before
production use.

Validate with `npm run check-template -- zip-hoodie`.
