# Sleeveless hooded jacket

Open `/mockup-lab?product=hoodie-vest-black`.

Only the black jacket from the supplied ImageKit reference is included. The
person, white shirt, sleeves, trousers and chest lettering are removed.
The ghost image retains the hood, sleeveless armholes, split pockets and ribbed hem.

The inset silhouette uses 0.8 px feathering. Fabric recolouring includes the
white-specific shadow treatment. The metallic zipper overlay remains fixed
while surrounding tape changes colour. Left and right chest logos avoid the zip.

Only a front view is available; sizing assumes a 52 cm chest and needs real
garment measurements for production use.

Validate with `npm run check-template -- hoodie-vest`.
